## 5.1 Markdown Homework
Using the .txt file I used github in order to change the format of the txt into markdown format (.md)
Another way of doing this would be to use
```bash
nano Zellman_P1.txt
```
This would open the in terminal text editor to change the words and format
I then just used a copy command to put the file in where I needed it 
```bash
cp Zellman_P1.txt/w3
cd w3
ls
```
To the synchronize the local and remote and make sure the file is in both
```bash
git add Zellman_p1.txt
git commit -m "Adding New Markdown format .txt file"
git push
git log
```
