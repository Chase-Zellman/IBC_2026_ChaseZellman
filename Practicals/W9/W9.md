## File Processing
For this we needed to write an R script that loads all the files in the `Saavedra2013` folder and report the number of rows, column, and proportion of 1 and 0 entries.
To start off I listed the files to see how many there was and made the empty data frame `MatrixStats` which would later hold my data.
```R
MatrixStats <- data.frame()
```
Then for my loop that would go through all the files I used for i in 1:59 because there was 59 file.
I made my variables that would hold all the information to be put into the data frame. `File` is constructed with whatever value of i it is on and it uses `paste0` in order to create the file name without any spaces.
Then `Current_File` gets the current file to be worked on by reading the table as a matrix and using `paste0` again to print the path and file name to get data from.
Then `Nrow` and `Ncol` use the value of the current file being worked on to get the values
`Current_p_1` and `Current_p_0` get sum of how many 1's and 0's there are divided by the length of the file which gives us the proportion.
Finally, these values are added into a data frame called `append` whcih stores the columns and data from the current file and uses `rbind` to join MatrixSats with append to add a row for every file.
```R
for(i in 1:59){
  File <- paste0("n",i,".txt")
  Current_File <- as.matrix(read.table(paste0("Saavedra2013/", File), header = F))
  Current_Nrow <- nrow(Current_File)
  Current_Ncol <- ncol(Current_File)
  Current_p_1 <- sum(Current_File == 1) / length(Current_File)
  Current_p_0 <- sum(Current_File == 0) / length(Current_File)
  append <- data.frame(File = File,
                       Nrow = Current_Nrow,
                       Ncol = Current_Ncol,
                       p_1 = Current_p_1,
                       p_0 = Current_p_0)
  MatrixStats <- rbind(MatrixStats, append)
}
```
Then the table is written in tsv format
```R
write.table(MatrixStats, file = "MatrixStats.tsv", sep = "\t", row.names = F )
```

### 2
First my working directory was in the `DataFiles` so I input the function into the script.
Then we needed to get a single file name and then the leaf area, name, time, and id.
In order to get all my files I used `list.files()` command to get all files in leafarea folder that eneded in `.JPG`
I then created my empty data frame `results` with empty columns.
My for loop is similar to the previous problem, it goes through all the files in the file list gets the area using the `getArea` function.
It then uses `paste0` to get the file. It gets the `name` by using strsplit of the file and seperating at the underscore or period.
`Time` is gotten by getting `name[1]` because the time is the thing before the underscore. 
Similar with `id` it is the things after the period so it is `name[2]`
It then uses `rbind` of the results with a data frame that has all the values to be put in for that file.
```R
source("leafarea/getArea.R")

file_list <- list.files(path = "leafarea/", pattern = "\\.JPG$")
print(file_list)

results <- data.frame(Time = character(),
                      ID = character(), 
                      Area = numeric())

for (file in file_list) {
 area <- getArea(paste0("leafarea/", file))
 name <- strsplit(file, "[_.]")[[1]]
 time <- name[1]
 id <- name[2]
 results <- rbind(results, data.frame(Time = time, ID = id, Area = area))
}

View(results)
```
