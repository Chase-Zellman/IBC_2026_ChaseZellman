## Disease Risk
### 1
First makes the table with read.table from the file, the seperater is a space and there are headings
Then it gets maximum sum of the clolumns we want
```R
#Disease Risk
#1
Euro_geno <- read.table("H938_Euro_chr6.geno", sep = " ", h=T)
str(Euro_geno)

maxsum <- Euro_geno$nA1A1 + Euro_geno$nA1A2 + Euro_geno$nA2A2
max(maxsum)
```

## 2
This time we are using rowSums() which we add max to, to get the max number and then the table we are taking them from "Euro_geno" which is what I named my table. Then we want columns 5-7 and na.rm = T skips any empty rows in the calculation
```R
max(rowSums(Euro_geno[, 5:7], na.rm = T))
```

### 3
Now we want to join the third column from SNP_risks to our previous table, so using cbind that was taught earlier  you bind the first table Euro_geno with SNP_risk but we only want the third column so we add in the [3] this is named Euro_geno_risk so I know its the combined table
```R
SNP_risk <- read.table("SNP_risks.csv", sep = ",", h=T)

Euro_geno_risk <- cbind(Euro_geno, SNP_risk[3])
str(Euro_geno_risk)
```

### 4
Here we want the average of how many individuals are heterozygous at sites associated with disease risk so we get the mean from A1A2 column and then now with our Risk column we just added we can search for Risk and Non-Risk which are the two variables in there 
```R
mean(Euro_geno_risk$nA1A2[Euro_geno_risk$Risk == "Risk"])
mean(Euro_geno_risk$nA1A2[Euro_geno_risk$Risk == "Non-Risk"])
```

## Data Cleanup
### 1
In this I read the file into R and then I used View() just to see the table better and see which column was the species column then using length it will output how many species are in the file
```R
Smith_Data <- read.table("Smith2003_data.txt", sep = "\t", h=F)
str(Smith_Data)
View(Smith_Data)
length(Smith_Data$V6)
```

### 2
To change the -999 to NA we do gsub which changes a value for another and then with clolumn 7 the log body mass and column 8 the raw body mass then write the new table and a new file with the clean data and it is in tsv format because the separator is "\t" or tab
```R
Smith_Data$V7 <- gsub("-999", "NA", Smith_Data$V7)
Smith_Data$V8 <- gsub("-999", "NA", Smith_Data$V8)
write.table(Smith_Data, file="Smith2003_data_clean.tsv", sep="\t", row.names=F)
View(Smith_Data)
```
