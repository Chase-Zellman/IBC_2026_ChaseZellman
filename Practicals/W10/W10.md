Then the odds are the toad rights divided by the number of trials, the difference of odds is that toads odds - 0.5 which is the probability for each hand, then the expirement odds are in the same way
Then the p value for that toad is the sum of the experiment compared to the toad difference divided by number of expiraments
``` R
toad_right <- c()
p_value<- c()
nexp <- 10000

for(i in 1:nrow(Toads)){
  num_trial <- Toad_Trials[i]
  toad_right <- c()
  for(j in 1:nexp){
    exp <-sample(c("R","L"), size = num_trial, prob = c(0.5,0.5), replace = T)
    right <- sum(exp =="R")
    toad_right[j] <- right
  }
  exp_odds <- toad_right/num_trial
  toad_diff <- abs(Toad_odds[i] - 0.5)
  exp_diff <- abs(exp_odds - 0.5)
  p_value[i] <- sum(exp_diff >= toad_diff)/nexp
}
```
Here I made a empty data frame to get handedness for each toad then a for loop to go through the number of rows for each toad
If the p value is greater than 0.05 which is the probability we used in class then it proves there's no preference. If its odds were over 0.5 for right counts then its right handed, otherwise left handed.
Finally, we add a new column to the main table with the p values and the handedness

```R
#1
library(readr)
Jiang2013_data <- read_delim("Jiang2013_data.csv", 
                             delim = "\t", escape_double = FALSE, 
                             trim_ws = TRUE)

Mating_Data <- Jiang2013_data

mean_r <- function(taxon){
  mean_value <- mean(Mating_Data$r[Mating_Data$Taxon == taxon])
  return(mean_value)
}

mean_r("Fish")
```

### 2
For this we need to run a sample on the fish again to check to see if the original r was not too high by getting a p value
So the taxon r comes from the mating data then we get the fish mean, create an empty data set, and set the number of randomizations to 50000
Then for the loop we take a sample from the r's 37 times to mimic how many fish there were and without replacing the values the correlation coefficient is the mean of that sample
Then to get the p from it we do the sum of the correlation coefficients compared to the mean r from fish / the number of times we ran it
I got `fish mean = 0.3971901` which is the mean r and then the p is '0.00304'
```R
Taxon_r <- Mating_Data$r
fish_mean <- mean_r("Fish")
cor_coef <- c()
num_random <- 50000
for(i in 1:num_random){
  exp <- sample(Taxon_r, size=37, replace = F)
  cor_coef[i] <- mean(exp)
}
fish_sample_p <- sum(cor_coef >= fish_mean)/num_random
print(fish_mean)

```
